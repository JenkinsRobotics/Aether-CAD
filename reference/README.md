# CAD behavior reference

The current supplied SolidCraft snapshot is `solidcraft-main/`, version
**0.23.0** in its root `Cargo.toml`, added on 2026-10-25.

Use this snapshot's contracts, workflows and tests when comparing behavior with
Aether CAD. The reference is separate from Aether's product engine and release
artifacts. Preserve its upstream license and attribution files.

The older 0.16.2 ZIP, archived bridge/source bundle and temporary extraction were
removed on 2026-10-25 at Jonathan's request. Existing roadmap reviews retain
their historical version labels; they do not establish parity with 0.23.0.
