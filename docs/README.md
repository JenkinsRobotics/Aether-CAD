# Aether CAD Documentation

All architecture, format specifications, release playbooks, roadmaps, and verification records live in this directory.

## Directory Layout

- **[architecture/](architecture/)** — Core architecture, engine boundary extraction, hybrid file design, and feature-tree adoption (`ARCHITECTURE.md`, `AETHER_CORE_EXTRACTION.md`, `HYBRID_DESIGN.md`, `FEATURE_TREE_ADOPTION.md`).
- **[formats/](formats/)** — Canonical file format specifications (`PART_FORMAT.md`, `DRAWING_FORMAT.md`).
- **[releases/](releases/)** — Release procedures, alpha notes, migration history, and status (`RELEASING.md`, `ALPHA_0_1.md`, `STATUS.md`, `MIGRATION.md`).
- **[roadmap/](roadmap/)** — Active engineering plans, engine design, and CAD parity trackers (`CAD_0_2.md`, `Aether_Engine_Design.md`, `SolidCraft_0_47_Parity.md`, `FreeCAD_Comparison_2026_10_30.md`, `Onshape_Feature_Parity.md`, etc.).
- **[reality/](reality/)** — Measured performance benchmarks, comparison datasets (`data/`), and verification snapshots (`STATUS.md`).
- **[ai-agent/](ai-agent/)** — Spacecraft MCP benchmark and agent verification references.
